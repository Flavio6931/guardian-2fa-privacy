# Guardián 2FA · Sitio web

Página de inicio y política de privacidad de **Guardián 2FA**, una extensión de navegador que genera códigos de verificación en dos pasos (2FA).

- 🌐 **Página de inicio:** [flavio6931.github.io/guardian-2fa-privacy/home](https://flavio6931.github.io/guardian-2fa-privacy/home/)
- 🔒 **Política de privacidad:** [flavio6931.github.io/guardian-2fa-privacy](https://flavio6931.github.io/guardian-2fa-privacy/)

## Qué hace la extensión

- Genera códigos **TOTP**, **HOTP** y de estilo **Steam**.
- Agrega cuentas escaneando el QR de la página, subiendo una imagen QR, pegando texto otpauth o escribiendo los datos.
- **Copia opcional en Google Drive**: tus códigos se cifran en tu dispositivo con una contraseña que eliges antes de guardarse en una carpeta privada de tu propio Drive. Google solo recibe datos cifrados.
- Sin analítica, publicidad ni rastreo; el desarrollador no tiene servidores y no puede ver tus códigos.

## Este repositorio

Contiene solo las páginas públicas que Google y la Chrome Web Store piden para publicar la extensión. El código de la extensión está en un repositorio aparte.

```
index.md        política de privacidad (inglés y español)
home/index.md   página de inicio (inglés y español)
_config.yml     título del sitio
```

GitHub Pages convierte los archivos Markdown en páginas web y las publica en `flavio6931.github.io/guardian-2fa-privacy/`.
